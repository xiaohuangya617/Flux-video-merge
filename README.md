# 视频拼接器 v1.3.1

一个 Windows 免安装视频拼接工具。它会检查多个视频的编码、分辨率、帧率和音频参数，在需要时自动对齐，再合并为一个视频。

## 下载和使用

[下载 Windows 完整运行包](https://github.com/xiaohuangya617/video-merger/releases/download/v1.3.1/video-merger-v1.3.1-windows-x64.zip)

1. 下载 ZIP 压缩包。
2. 右键选择“解压全部”，不要只提取 EXE 文件。
3. 打开解压后的文件夹，双击 `视频拼接器.exe`。

程序无需安装 Python、Node.js 或 FFmpeg；压缩包里的文件必须保持原目录结构。

## 功能

- 支持拖入视频文件或文件夹，也可以通过按钮选择文件和文件夹。
- 自动递归扫描文件夹中的 `mp4`、`mkv`、`mov` 视频。
- 支持列表排序、清空列表和批量合并任务。
- 自动检查视频编码、分辨率、帧率、像素格式、音频编码、采样率和声道等参数。
- 参数一致时优先无损拼接；可以无损规整的差异先重封装，无法无损处理时自动转码对齐。
- 支持输出 `mp4`、`mkv`、`mov`。
- 显示处理进度和预计剩余时间，支持取消任务。
- 检查输出文件的视频帧数、音画时长、时间戳和音视频流结构。
- 支持任务队列、输出文件已存在时的处理选择和处理日志。
- 可将源视频移入系统回收站，误操作时可以从回收站还原。

## 输入和输出限制

- 当前版本只扫描 `mp4`、`mkv`、`mov`，不会自动处理 `avi`、`webm`、`ts` 等其他扩展名。
- 输出格式只有 `mp4`、`mkv`、`mov`，不支持 `webm`。
- 视频参数差异较大时会自动转码，耗时和输出文件大小会明显增加。
- 合并前需要足够的临时磁盘空间；程序会检查输出目录和临时目录的可用空间。
- 建议先用少量副本测试，再处理唯一原件。启用移入回收站功能前请确认源文件列表。

- 当前发布包只有编译后的 Windows 二进制，没有同步提供源代码，不能直接用于二次编译。
